# Antigravity Proxy (приложение)

Маленькое окно для Windows, которое держит локальный прокси и запускает через
него нужные программы.

## Что умеет

| Кнопка / элемент | Что делает |
|---|---|
| **Применить** | записывает адрес/порт/логин/пароль прокси в конфиг Xray и перезапускает его |
| **Проверить выход** | показывает, из какой страны и с какого IP реально выходит трафик (`ipinfo.io`) |
| **Запустить Antigravity** | находит установку автоматически и запускает её с `AG_LS_PROXY` на локальный прокси |
| **Патч** | находит `Open_AG_Patcher*.exe` в «Загрузках», запускает от администратора и подставляет путь к Antigravity |
| **Браузер (Gemini / AI Studio)** | открывает Chrome/Edge в отдельном профиле с прокси и сразу `aistudio.google.com` |
| **OpenCode** | запускает OpenCode с прокси в переменных окружения |
| **Системный прокси** | включает/выключает прокси `127.0.0.1:10809` для всех программ, использующих настройки Windows |

Статус патча определяется по `language_server.exe`: если в бинаре есть метка
`inexigible` — патч применён.

## Установка

```
powershell -ExecutionPolicy Bypass -File install-app.ps1
```

(от администратора). Скрипт скопирует файлы в `%LOCALAPPDATA%\AntigravityProxy`,
создаст ярлык на рабочем столе и в меню Пуск.

## Где лежат данные

- конфиг Xray: `%LOCALAPPDATA%\XrayNL\config.json`
- профиль браузера, открытого через прокси: `%LOCALAPPDATA%\AntigravityProxy\BrowserProfile`
- журнал доступа: `%LOCALAPPDATA%\XrayNL\access.log`

В репозиторий эти файлы не попадают — там могут быть ваши пароли.

## OpenCode из терминала

Чтобы CLI-версия тоже ходила через прокси, запускайте её так:

```
set HTTP_PROXY=http://127.0.0.1:10809
set HTTPS_PROXY=http://127.0.0.1:10809
opencode
```

Или включите «Системный прокси» в приложении — тогда новые процессы подхватят
настройки, если клиент их читает.
