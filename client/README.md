# Antigravity Proxy (Клиентская часть)

Windows-приложение для маршрутизации трафика рабочих инструментов через локальный и внешний прокси.

## Компоненты клиента

- **`AntigravityProxy.exe`** — основное приложение (Windows Forms, .NET 4.x). Управляет локальным Xray, переключает профили, замеряет скорость и запускает связанные программы.
- **`AntigravityProxySetup.exe`** — мастер установки с графическим интерфейсом. Создаёт ярлыки (Рабочий стол, меню Пуск, панель задач) и регистрирует приложение в «Установка и удаление программ» Windows.
- **`Uninstall.exe`** — деинсталлятор для чистого удаления приложения и его ярлыков.
- **`build.cmd`** — скрипт компиляции всех трёх `.exe` через встроенный компилятор `csc.exe`.

## Что умеет приложение

| Кнопка / элемент | Что делает |
|---|---|
| **Выбор прокси (список)** | Быстрое переключение активного профиля прямо из главного окна в 1 клик |
| **↻ Статус** | Показывает статус Xray, выходной IP, страну, город и задержку (пинг) в мс |
| **⚡ Скорость** | Быстрый замер реальной скорости загрузки (Мбит/с) и пинга через Cloudflare CDN |
| **Настройки** | Добавление, редактирование, удаление нескольких серверов прокси, проверка соединения и выбор темы |
| **▶ Запустить Antigravity** | Находит установку автоматически и запускает её с `AG_LS_PROXY` на локальный прокси |
| **Патч** | Находит `Open_AG_Patcher*.exe` в «Загрузках», запускает от администратора и подставляет путь к Antigravity |
| **Браузер (Gemini / AI Studio)** | Открывает Chrome/Edge в отдельном профиле с прокси и сразу `aistudio.google.com` |
| **✈ Telegram** | Запуск Telegram Desktop с автоматическим подключением через локальный SOCKS5-прокси (порт 10808) |
| **OpenCode** | Запускает OpenCode с прокси в переменных окружения (GUI или CLI) |
| **Системный прокси** | Включает/выключает прокси `127.0.0.1:10809` для всех программ, использующих настройки Windows |

## Пути к файлам в системе

- Настройки приложения и профили прокси: `%LOCALAPPDATA%\AntigravityProxy\settings.json`
- Конфигурация локального Xray: `%LOCALAPPDATA%\XrayNL\config.json`
- Профиль браузера через прокси: `%LOCALAPPDATA%\AntigravityProxy\BrowserProfile`
- Лог-файлы: `%LOCALAPPDATA%\XrayNL\access.log`

## Сборка

```cmd
build.cmd
```

## Сторонние компоненты

- Кнопка **«Патч»** в интерфейсе предназначена для удобного вызова сторонней утилиты **Open AG Patcher** от команды **AvenCores** (лицензия **GPL-3.0**). Утилита не поставляется в составе репозитория; приложение помогает найти её в папке «Загрузки» и запустить с правами администратора.
- В качестве локального шлюза используется **Xray-core** (лицензия **MPL-2.0**).
