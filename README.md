# Antigravity Proxy — рабочий обход блокировки Antigravity в РФ

Набор инструментов, который поднимает Antigravity (Google) в России: локальный
DNS без подмены, зарубежный прокси, автозапуск и маленькое приложение для смены
прокси.

Проверено на Windows 11 + Antigravity 2.0 (сборка 2.28.x) в ноябре 2026.

---

## Как это работает

```
Antigravity ──► 127.0.0.1:10809 (локальный Xray)
                      │
                      └──► Резидентный HTTP-прокси (США) ──► Google
```

- **Локальный Xray** принимает HTTP/SOCKS на `127.0.0.1` и отправляет трафик в
  выбранный апстрим. Приложение и `language_server` видят обычный локальный прокси.
- **Резидентный прокси** даёт зарубежный IP. Google проверяет страну
  выхода — с датацентровых адресов часто отвечает `400 User location is not supported`,
  с резидентных работает стабильно.
- **AGDNS** — локальный DNS-резолвер поверх DNS-over-HTTPS. Нужен, когда провайдер
  подменяет ответы для доменов Google (`127.65.71.x` вместо настоящих адресов).

## Что внутри

| Папка | Что это |
|---|---|
| `agdns/` | локальный DNS-резолвер (DoH, кэш, защита от подмены, автозапуск, сторож) |
| `client/` | приложение «Antigravity Proxy» для Windows + установщик ярлыка |
| `tools/` | утилиты: диагностика цепочки (`diag.ps1`), блокировка QUIC (`block-quic.ps1`) |
| `docs/` | заметки: хронология тестов, решения проблем, скриншоты интерфейса |

## Быстрый старт (Windows)

1. Запустите `client/install-app.ps1` от администратора — он поставит приложение в
   `%LOCALAPPDATA%\AntigravityProxy` и создаст ярлык на рабочем столе.
2. Откройте ярлык **Antigravity Proxy**.
3. Впишите данные прокси: адрес, порт, логин, пароль → **Применить**.
4. Убедитесь, что статус зелёный: «Прокси работает. Выход: …».
5. Нажмите **Запустить Antigravity**.

## DNS (AGDNS)

Ставится отдельно, нужен если провайдер подменяет DNS:

```
agdns\install.cmd      (от администратора)
agdns\check.cmd        (проверка)
agdns\uninstall.cmd    (откат)
```

Резолвер слушает `127.0.0.1:53`, ходит по DoH в Google/Cloudflare/AdGuard,
отбрасывает ответы `127.0.0.0/8` и `0.0.0.0`.

---

## Важно про безопасность

В репозитории **нет** паролей, ключей и адресов прокси — только шаблоны.
Свои данные держите в `%LOCALAPPDATA%\XrayNL\config.json` (этот файл в `.gitignore`).
