# Antigravity Proxy — удобный менеджер прокси для Antigravity и браузера

[![GitHub Release](https://img.shields.io/github/v/release/dz633187-star/antigravity-proxy?color=38bdf8&style=flat-square)](https://github.com/dz633187-star/antigravity-proxy/releases/latest)
[![Platform](https://img.shields.io/badge/platform-Windows%2010%20%2F%2011-blue?style=flat-square)](https://github.com/dz633187-star/antigravity-proxy)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=flat-square)](LICENSE)

Автономное компактное Windows-приложение (`.exe`) для управления локальным прокси, мгновенного переключения между серверами, замера реальной скорости и комфортной работы с **Antigravity**, **OpenCode**, **Gemini** и **Google AI Studio** из РФ.

---

## ⚡ Быстрый старт (Скачать)

Самый простой способ установки:
1. Перейдите в **[Релизы (GitHub Releases)](https://github.com/dz633187-star/antigravity-proxy/releases/latest)**.
2. Скачайте **`AntigravityProxySetup.exe`** (готовый инсталлятор).
3. Запустите инсталлятор, выберите нужные ярлыки (Рабочий стол, меню «Пуск», панель задач) и нажмите **«Установить»**.
4. Запустите приложение из меню «Пуск» или с рабочего стола, откройте **«Настройки»**, впишите ваши данные прокси и нажмите **«Сохранить»**.

> **Для портативного использования**: вы также можете скачать автономный **`AntigravityProxy.exe`** напрямую из релиза.

## 🚀 Основные возможности

| Функция | Описание |
|---|---|
| **Выпадающий список прокси** | Мгновенное переключение активного профиля прямо из главного окна без зависания интерфейса. |
| **⚡ Замер скорости** | Реальная скорость загрузки (Мбит/с) и пинг (мс) через CDN Cloudflare без кэширования сокетов. |
| **Менеджер серверов** | Добавление, редактирование и удаление любого количества серверов (HTTP / SOCKS) с проверкой соединения напрямую. |
| **▶ Запуск Antigravity** | Автоматический поиск установленного Antigravity и запуск с корректными переменными `AG_LS_PROXY`. |
| **Браузер для AI Studio** | Запуск Chrome/Edge в отдельном чистом профиле через прокси с открытием `aistudio.google.com`. |
| **OpenCode (GUI и CLI)** | Запуск OpenCode с проксированием окружения в один клик. |
| **Системный прокси** | Включение/выключение прокси `127.0.0.1:10809` в системных параметрах Windows для всех программ. |
| **Инсталлятор и деинсталлятор** | Удобный установщик `AntigravityProxySetup.exe` и корректное удаление через системные «Параметры Windows». |

## 🏗 Архитектура работы

```
Antigravity / Браузер / OpenCode
              │
              ▼
   127.0.0.1:10809 (Локальный Xray)
              │
              ▼
   Выбранный прокси-сервер (VPS / Резидентный прокси)
              │
              ▼
       Google Cloud / AI Studio / APIs
```

- **Локальный Xray** принимает входящий трафик на `127.0.0.1:10809` (HTTP) и `127.0.0.1:10808` (SOCKS) и прозрачно маршрутизирует его в выбранный вами апстрим.
- **Antigravity Proxy** управляет активным конфигом, контролирует процесс Xray, проверяет доступность узлов, пинг и скорость.
- **AGDNS** *(опционально)* — локальный DNS-over-HTTPS резолвер для обхода подмены DNS-ответов провайдерами.

## 📦 Структура репозитория

```
antigravity-proxy/
├── client/                     # Исходный код и бинарники клиентской части
│   ├── AntigravityProxy.cs     # Исходный код основного приложения (C# WinForms)
│   ├── AntigravityProxy.exe    # Скомпилированный бинарник приложения (~72 КБ)
│   ├── Installer.cs            # Исходный код мастера установки
│   ├── AntigravityProxySetup.exe # Готовый инсталлятор
│   ├── Uninstall.cs            # Исходный код деинсталлятора
│   ├── Uninstall.exe           # Деинсталлятор
│   ├── build.cmd               # Скрипт сборки всех компонентов (.NET Framework csc)
│   └── install-app.ps1         # Тихий PowerShell-скрипт установки
├── agdns/                      # Локальный DNS-резолвер (DoH, кэш, защита от подмены)
├── tools/                      # Вспомогательные утилиты (диагностика, блокировка QUIC)
└── docs/                       # Документация и скриншоты
```

## 🛠 Сборка из исходников

Для сборки всех исполняемых файлов не требуется Visual Studio — достаточно встроенного компилятора Windows `.NET Framework 4.x`:

```cmd
cd client
build.cmd
```

Скрипт автоматически скомпилирует:
1. `AntigravityProxy.exe`
2. `Uninstall.exe`
3. `AntigravityProxySetup.exe`

## 🔒 Безопасность

- В репозитории **нет** IP-адресов, паролей или токенов.
- Настройки и учетные данные серверов сохраняются локально на вашей машине по пути:  
  `%LOCALAPPDATA%\AntigravityProxy\settings.json` (файл защищён правилами `.gitignore`).
