# NL-VPS — зарубежный выход для Antigravity

Схема: **VPS в Нидерландах** с Xray (VLESS + REALITY на 443) → локальный клиент
Xray на Windows (`127.0.0.1:10809`) → анлокер/приложение ходит в Google через
этот прокси. Снаружи трафик выглядит как обычный HTTPS к `www.microsoft.com`,
поэтому DPI его не трогает.

## 1. Что купить

- Любой VPS в **Нидерландах** (Aeza, Timeweb Cloud, RUVDS, Hetzner, VDSina).
- ОС: **Ubuntu 24.04** (или 22.04 / Debian 12).
- Минимум: 1 vCPU, 1 ГБ RAM, 10 ГБ диска.
- Доступ: root-пароль или SSH-ключ.
- В панели провайдера: порт **TCP 443 открыт** (обычно открыт по умолчанию).

## 2. Установка на сервер

Откройте веб-консоль сервера (VNC/Console в панели) и вставьте одну команду из
файла `one-liner.txt`. Если вы не root — сначала выполните `sudo -i`.

Скрипт (`setup-min.sh`) сам:

1. ставит зависимости и Xray;
2. генерирует UUID, пару ключей REALITY и shortId;
3. пишет конфиг на порт 443 с маскировкой под `www.microsoft.com`;
4. включает BBR;
5. запускает службу `xray`;
6. печатает готовую ссылку `vless://...`.

Скопируйте эту ссылку — она короткая (около 200 символов).

## 3. Установка клиента на Windows

Двойной клик по `install-client.cmd`, вставьте `vless://...`, Enter.

Скрипт:

1. скачивает Xray для Windows;
2. пишет конфиг в `%LOCALAPPDATA%\XrayNL\config.json`;
3. запускает локальный прокси `127.0.0.1:10809` (HTTP) и `:10808` (SOCKS);
4. проверяет выход через `ipinfo.io` — должен быть **NL**;
5. проверяет доступ к `daily-cloudcode-pa.googleapis.com` — ждём `401`;
6. регистрирует автозапуск `XrayNL`.

## 4. Подключение Antigravity

В AGUnlocker: **«Настройки для опытных» → «Свой прокси»** → `127.0.0.1:10809` →
включить → **«Включить всё»**.

Если поле не принимает такой формат — попробуйте `http://127.0.0.1:10809`.

## Проверка

```powershell
# выход через прокси
curl.exe -x http://127.0.0.1:10809 https://ipinfo.io/json
```

Должно вернуть `"country": "NL"`.

## Если что-то не так

| Симптом | Что смотреть |
|---|---|
| `xray` не стартует | `journalctl -u xray -n 50 --no-pager` |
| клиент не открывает порт | `%LOCALAPPDATA%\XrayNL\install.log` |
| выход не NL | конфиг клиента, `pbk`/`sid` из ссылки |
| Google отвечает 400 | аккаунт/регион, не сеть |

## Откат

- Windows: `Get-Process xray \| Stop-Process`; удалить задачу `XrayNL`;
  удалить папку `%LOCALAPPDATA%\XrayNL`.
- Сервер: `systemctl disable --now xray`; удалить `/usr/local/etc/xray`.
